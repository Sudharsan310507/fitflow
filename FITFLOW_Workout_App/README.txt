FITFLOW - Personalized Workout Planner

Open index.html or use VS Code Live Server.

Features:
- Gender, age, height, weight and fitness-level setup
- Multiple fitness goals
- Home/Gym/Both personalization
- Workout duration and weekly frequency
- Activity level
- Dynamic weekly workout plan
- BMI and estimated calorie requirement
- Exercise selection based on fitness level and location
- Workout completion and progress tracking with LocalStorage
- Responsive premium dark editorial design

BMI and calorie values are estimates for educational/demo purposes, not medical advice.
